## Start a conversation

From a signed-in workspace, open **Agents** in the right-side panel. The **Agents** tab opens with your primary agent selected. In an empty chat, the page says “Ask anything to start a conversation.” Enter a message in **Message your agent** (the field may show the agent’s name instead) and choose **Send message**. Your first message starts a conversation.

While you are present in a chat, the agent uses your signed-in session; **Background agent access** is not needed for a conversation you are watching. If the chat connection drops, the page reconnects and can resume a response that is still streaming. Reopening a conversation loads its transcript.

## Allow agent work while you’re away

This setting controls whether agents can act for you while you’re away, such as when a trigger or schedule runs. In the workspace, open your profile menu, choose **Settings**, then choose **Account**. Under **What your agents may do**, find **Background agent access** and select **Turn on**. Complete the authorization flow; Oryxa returns you to the account settings. When enabled, the status reads “Your agents can act for you while you’re away.”

To turn it off later, select **Revoke**, then **Revoke access**. If the row says “Not available on this server,” background access is not enabled on that server.
