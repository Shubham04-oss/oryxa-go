```mermaid
flowchart LR
  member["Member's browser"]

  subgraph cloudflare["Cloudflare"]
    worker["Web app Worker"]
    objects["Conversation Durable Objects"]
    tunnel["Tunnel routes<br/>app /v1 and api host"]
    worker <--> objects
  end

  member -->|"app and conversation requests"| worker
  member -->|"same-origin /v1 requests"| tunnel

  subgraph ecs["AWS ECS Fargate · oryxa Go services"]
    api["Go listener · HTTP and background work"]
    auth["Auth"]
    agents["Agents / primary"]
    apps["Apps"]
    files["Files"]
    email["Email consumer"]
    realtime["Realtime bridge<br/>when configured"]
    api --> auth
    api --> agents
    api --> apps
    api --> files
  end

  tunnel --> api
  objects -->|"agent run requests"| agents
  objects -.->|"conversation events, when configured"| realtime
  realtime -.->|"conversation purge"| objects
  agents -->|"member-scoped app tools"| apps

  subgraph aws["AWS services"]
    cognito["Cognito"]
    postgres[("RDS PostgreSQL")]
    events["EventBridge rule + email queue"]
    s3[("S3")]
    ses["SES"]
  end

  auth <-->|"sign-in and identity"| cognito
  api -->|"shared service state"| postgres
  files -->|"file objects"| s3
  auth -->|"auth delivery events"| events
  events --> email
  email -->|"system email"| ses

  subgraph providers["Provider paths · configuration-dependent"]
    google["Google identity provider"]
    vertex["Vertex AI / Gemini"]
    composio["Composio"]
  end

  cognito -.->|"when Google sign-in is enabled"| google
  agents -.->|"configured model calls"| vertex
  apps -.->|"connected app flow and tool calls"| composio
```

This is a source-based map of the core browser, agent, app, file, auth, and email paths, not a live traffic trace. Cloudflare routes, provider calls, and the Realtime bridge depend on deployment configuration. Dodo billing is omitted from the beta scope; Slack bot and native phase-2 integration paths are not shown as active routes.
