# Getting started

## Sign in

At the sign-in screen, enter your email and password, then select **Sign in**. The page may also offer Google sign-in, depending on Oryxa's authentication configuration. If you don't have an account, select **Create an account**.

## Create an account and verify your email

Enter your name, work email, and a password with at least 12 characters, including uppercase and lowercase letters, a number, and a symbol. Select **Create account**. Check the inbox for the address you entered and open the verification link.

Verification links expire after 24 hours. If a link has expired, was already used, or is incomplete, select **Send a new link** on the verification page and enter the same email address. Once the page confirms **Email verified**, sign in.

## Accept a workspace invitation

Open the invitation link from your email. If you're signed out, sign in and Oryxa will return you to the invitation. Use the email address the invitation was sent to, then select **Accept invitation**. Oryxa opens the workspace after you join.

If you're signed in with a different account, select **Sign out and use another account**, then sign in with the invited address. If you need to create an account first, use the invited address, verify it, then reopen the original invitation link and sign in. The verification screen sends you to sign-in without preserving the invitation redirect.

If the invitation is no longer available, ask the workspace admin for a new one. If the workspace has reached its member limit, ask an owner to raise it.
